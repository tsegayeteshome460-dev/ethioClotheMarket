# Storefront

The storefront is a React application built with Vite. Its application source,
components, pages, and assets live in `src/`; static files live in `public/`.

Run `npm run dev` from this directory, or use `npm run dev:frontend` from the
project root. The Vite development server proxies `/api` requests to the backend
at `http://127.0.0.1:5000`.
